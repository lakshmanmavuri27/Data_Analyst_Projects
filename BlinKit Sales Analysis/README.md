# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview

Developed an interactive **Blinkit Sales Analysis Dashboard** using Microsoft Power BI to analyze grocery sales data, product performance, and outlet characteristics. The dashboard provides insights into sales distribution, product categories, outlet locations, and customer ratings to support data-driven decision-making.

## Tools & Technologies
- **Power BI Desktop:** Dashboard development and data visualization
- **Power Query:** Data cleaning and transformation
- **DAX:** Calculated measures and KPI development

## Key Features
- Cleaned and standardized data using Power Query.
- Created DAX measures for Total Sales, Average Sales, Average Rating, Unique Products, and Total Outlets.
- Designed interactive KPI cards and charts to visualize business performance.
- Analyzed sales by Item Type, Fat Content, Outlet Type, and Outlet Location.
- Compared sales performance based on Outlet Establishment Year.
- Implemented interactive slicers for Outlet Type and Outlet Size.

## Dashboard KPIs

 Total Sales 
 Average Sales 
 Total Item Records 
 Unique Products 
 Average Rating 
 Total Outlets 

## Key Insights
- **Fruits and Vegetables** and **Snack Foods** are the leading product categories by sales.
- **Low Fat products** contribute approximately 64.6% of total sales.
- **Tier 3 outlets** generate the highest sales, approximately $472K.
- **Supermarket Type 1** is the highest-performing outlet type, contributing approximately $788K.
- The dashboard summarizes approximately **$1.20M in recorded sales** across the dataset.
