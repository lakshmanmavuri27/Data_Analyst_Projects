# 🍫 Chocolate Shipment Analysis | Power BI

## 📌 Project Overview

Chocolate Shipment Analysis is a data analytics project developed using Microsoft Power BI to analyze chocolate sales and shipment performance.

The project transforms raw sales and shipment data into an interactive dashboard, helping users understand sales trends, product performance, country-wise sales distribution, and salesperson performance.

## 🎯 Project Objectives

- Analyze overall chocolate sales performance.
- Identify top-performing chocolate products.
- Evaluate country-wise sales performance.
- Analyze individual salesperson performance.
- Track shipment quantities and trends.
- Identify sales patterns and business opportunities.
- Present actionable insights through an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and KPIs.
- **Data Modeling** – Organizing data for analysis.

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Total Boxes Shipped
- Total Shipments

- Top-Selling Product
